# Rebounce 2.0 Complete Tracker 🚀

A dedicated mobile-first web application designed for JEE 2027 students following the **Rebounce 2.0** schedule (Chemistry & Mathematics) and dynamic Physics weightage analysis.

## ✨ Features
- **3-Folder Structure:** Clean, intuitive mobile navigation from Dashboard -> Subjects -> Chapters -> Daily Tasks.
- **3-State Checkboxes:** Tap once for **Partially Completed** (Yellow), twice for **Fully Completed** (Green), and a third time to reset.
- **Passwordless Authentication:** Secure, frictionless login via Firebase Email Link Magic Links.
- **Cloud Persistence:** Automatic background syncing with Cloud Firestore so your progress is remembered across all your devices.
- **Live Progress Analytics:** Real-time progress bars calculating completion percentages for Lectures, DPPs, Practice Modules, Tests, and PYQs.

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML5, Tailwind CSS (via CDN)
- **Backend & Auth:** Firebase (Authentication & Cloud Firestore)
- **Hosting:** GitHub Pages
